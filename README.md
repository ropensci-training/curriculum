# curriculum

This is the repo of the book for the first edition—**in progress**—of the training material for R package developers and maintainers based on the rOpenSci Champions Program Training.

At the beginning of each chapter, you’ll find a note indicating its status: complete, being refined, being restructured, being migrated, or a draft.
This will help you decide whether to read the content and provide your input (we are always very grateful for any feedback you can give us).

In this book, we follow the rOpenSci Code of Conduct. By contributing to this book, you agree to abide by its terms.

This website is developed under Yanina Bellini Saibene's [Sovereign Tech Fellowship](https://www.sovereign.tech/news/meet-the-2026-sovereign-tech-fellows).
